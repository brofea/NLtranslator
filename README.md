# 奶龙语翻译器

一个把文本加密成「奶龙语」的小工具，TypeScript + Vite 构建。

## 功能

- 把原文加密成由「哈」和不可见零宽字符组成的奶龙语
- 把奶龙语解密回原文
- 一键复制结果，实时统计「哈」与零宽字符数量

## 使用

```bash
npm install
npm run dev      # 开发预览
npm run build    # 类型检查 + 构建到 dist/
npm run preview  # 预览构建产物
```

## 加密原理

1. 将文本按 UTF-8 编码为字节
2. 每个字节转换为 8 位二进制，按 3 位一组补零分组
3. 每组 3 位二进制映射为 8 种零宽字符之一（U+200B、U+200C、U+200D、U+200E、U+200F、U+2060、U+2061、U+2062）
4. 每个零宽字符前加一个「哈」（U+54C8），末尾再补一个「哈」

解密时去掉所有「哈」，按 3 个零宽字符还原 9 位取前 8 位得到原字节，再按 UTF-8 解码。相比 2 字符集（1 位/字符），加密长度约为原来的 3/8。
