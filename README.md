# 奶龙语翻译器

一个把文本加密成「奶龙语」的小工具，TypeScript + Vite 构建。

## 功能

- 把原文加密成由「哈」和不可见零宽字符组成的奶龙语
- 把奶龙语解密回原文
- 一键复制结果，实时统计「哈」与零宽字符数量

## 使用

```bash
npm install
npm run dev      # 开发预览
npm run build    # 类型检查 + 构建到 dist/
npm run preview  # 预览构建产物
```

## 加密原理

1. 将文本按 UTF-8 编码为字节
2. 每个字节转换为 8 位二进制
3. 二进制位 `0` 映射为零宽空格（U+200B），`1` 映射为零宽非连接符（U+200C）
4. 每个零宽字符前加一个「哈」（U+54C8），末尾再补一个「哈」

解密时去掉所有「哈」，按映射关系还原二进制位即可得到原文。
